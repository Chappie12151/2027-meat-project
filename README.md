# 2027 оны махны төсөл

GitHub Pages дээр байрлуулах статик төслийн танилцуулгын эхний хувилбар.

## GitHub Pages-ээр нийтлэх

1. GitHub дээр `2027-meat-project` нэртэй public repository үүсгэнэ.
2. `index.html`, `style.css`, `README.md` файлуудыг repository-ийн үндсэн хэсэгт оруулж commit хийнэ.
3. Repository-ийн **Settings → Pages** хэсэгт **Deploy from a branch** сонгоно.
4. `main` салбар болон `/(root)` хавтсыг сонгож хадгална.
5. Нийтлэгдсэн хаяг `https://USERNAME.github.io/2027-meat-project/` хэлбэртэй байна.

Одоогоор малын тоо, үнэ, зардал, хөрөнгө оруулалтын дүн оруулаагүй. Судалгаагаар баталгаажсан мэдээлэл гарсны дараа `index.html` дахь холбогдох бичвэрийг шинэчилнэ.
